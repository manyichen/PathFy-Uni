# PathFy 首页五阶段职业路径体验说明

> 实施阶段：p5.js 全站增强阶段 4B  
> 完成日期：2026-08-18  
> 实施状态：已完成并通过完整回归测试

## 1. 功能概述

首页“职业决策链路”区域新增“体验五阶段职业路径”按钮。用户主动点击后，页面才异步加载 p5.js 场景并打开体验弹层，用约 7 秒演示 PathFy 的完整产品流程：

```text
材料 → 画像 → 匹配 → 计划 → 复盘
         ↑                 │
         └──── 反馈校准 ────┘
```

该体验用于解释产品模块之间的关系，不读取、推测或修改用户的材料、画像、岗位匹配和报告进度。

## 2. 用户可见的新功能

### 2.1 主动体验入口

- 入口名称为“体验五阶段职业路径”；
- 入口位于首页现有行动面板中，不替换原有模块入口；
- 用户没有点击入口时，不创建 Canvas，也不加载体验组件；
- 关闭弹层后，键盘焦点自动返回入口按钮。

### 2.2 五阶段自动引导

打开弹层后，普通动态模式会按以下顺序自动播放：

| 阶段 | 页面说明 | 对应真实入口 |
| --- | --- | --- |
| 材料 | 整理简历、项目、竞赛和作品，建立可追溯能力证据 | `/profile` |
| 画像 | 将材料映射到八维能力，保留分值与证据来源 | `/profile` |
| 匹配 | 比较个人能力与真实岗位要求、优势和差距 | `/match` |
| 计划 | 将目标岗位与能力差距拆解为行动任务 | `/report` |
| 复盘 | 根据月度实际结果校准后续路线 | `/report#review` |

每个阶段停留约 1.35 秒。到达“复盘”后自动播放停止，并显示复盘结果返回画像与计划的反馈回路。

### 2.3 手动交互

用户可以：

- 暂停或继续自动播放；
- 使用“上一步”和“下一步”逐阶段查看；
- 点击五个 DOM 阶段按钮直接跳转；
- 点击 Canvas 中的阶段节点切换当前阶段；
- 在最后阶段选择“再次体验”；
- 从当前阶段说明卡直接进入对应业务模块。

用户进行手动选择后，自动播放会暂停，避免画面继续跳转干扰阅读。

## 3. 新增视觉效果

### 3.1 星空职业路径

Canvas 使用深蓝至深紫渐变背景和稳定分布的微光星点，建立“职业探索路线”氛围。星点位置由固定算法生成，同一尺寸下不会随机抖动。

五个阶段沿柔和起伏的曲线路径排布，每个阶段具有独立颜色和语义图形：

- 材料：多张叠放的材料卡片；
- 画像：八边形能力轮廓；
- 匹配：两个相互连接的匹配圆环；
- 计划：带节点的行动路线；
- 复盘：带回转箭头的循环图形。

### 3.2 路径建立动画

- 阶段切换时，发光曲线从上一节点延伸到当前节点；
- 单次过渡时间约为 680ms，并使用缓出曲线减弱机械感；
- 当前节点放大并增强外圈与光晕；
- 已到达节点保持彩色，未到达节点降低亮度；
- 每段过渡结束后调用 `noLoop()`，画布不持续空转。

### 3.3 复盘反馈回路

进入最后的“复盘”阶段后，画布底部显示一条从复盘返回画像的虚线曲线，并标注“复盘结果回到画像与计划”。该效果表达持续校准关系，不代表用户已经完成复盘。

### 3.4 DOM 与 Canvas 同步

Canvas 节点、五阶段按钮、阶段说明卡和进度控制使用同一份状态：

- 点击任意节点会同步更新阶段按钮的当前状态；
- 阶段说明、颜色和模块入口同步切换；
- 自动播放与手动操作不会形成两套互相冲突的进度。

## 4. 动效与运行边界

- 首页不存在常驻全屏 Canvas；
- 体验组件仅在用户点击后异步加载；
- 每次阶段动画完成后停止绘制；
- 浏览器标签页进入后台时暂停自动引导和场景运行；
- 弹层关闭后清理定时器、媒体查询监听、可见性监听和 p5 实例；
- 场景帧率限制为 30 FPS；
- Canvas 像素密度继续由公共宿主管理，避免高分屏无边界扩大开销。

## 5. 低动态、键盘与失败回退

### 5.1 减少动态效果

当系统启用 `prefers-reduced-motion: reduce` 时：

- 不自动播放五阶段流程；
- 不执行持续路径动画；
- 暂停/播放按钮禁用；
- 用户仍可通过阶段按钮或前后按钮手动浏览全部内容。

### 5.2 无障碍支持

- Canvas 设置为展示性内容并对读屏器隐藏；
- 全部阶段名称、说明、顺序和模块入口均由语义化 DOM 提供；
- 当前阶段使用 `aria-current="step"` 标记；
- 阶段变化通过 `aria-live` 区域播报；
- 所有核心操作均可通过键盘完成。

### 5.3 失败回退

p5.js 下载或绘制失败时，仅动态画面降级。页面会显示提示，并继续保留：

- 五阶段 DOM 按钮；
- 当前阶段说明；
- 上一步、下一步和重播操作；
- 进入真实业务模块的入口。

## 6. 数据与隐私边界

本功能使用固定产品流程数据，不接收用户业务对象。场景不会：

- 读取上传材料或简历内容；
- 读取画像分数或人格结果；
- 推测用户当前所处阶段；
- 修改匹配、报告或复盘状态；
- 将演示阶段保存为用户进度。

组件会派发本地事件 `pathfy:workflow-experience`，事件类型包括：

- `open`：打开体验；
- `stage`：切换阶段；
- `complete`：到达复盘阶段；
- `exit`：退出体验。

事件只包含事件名、阶段键和发生时间。目前没有接入外部统计服务，也不会主动上传数据。

## 7. 项目结构

```text
frontend/app/
├─ components/
│  ├─ HomeProcessFlow.vue
│  └─ visualization/home/
│     └─ HomeWorkflowExperience.vue
├─ types/
│  └─ home-workflow-experience.ts
└─ utils/
   ├─ home-workflow-metrics.ts
   └─ visualization/
      ├─ home-workflow-adapter.ts
      └─ scenes/
         └─ home-workflow-scene.ts

frontend/tests/
├─ unit/
│  └─ home-workflow-adapter.test.ts
└─ e2e/
   └─ home-workflow-experience.spec.ts
```

职责划分：

- `HomeProcessFlow.vue`：首页入口、异步加载和关闭后焦点恢复；
- `HomeWorkflowExperience.vue`：弹层状态、自动引导、DOM 控件、低动态和生命周期；
- `home-workflow-adapter.ts`：固定阶段、真实入口、连接关系和边界处理；
- `home-workflow-scene.ts`：p5.js 绘制、节点命中和有限动画；
- `home-workflow-metrics.ts`：无个人数据的本地事件接口；
- 单元测试与浏览器测试：验证数据语义、交互、回退和资源隔离。

## 10. 后续建议

当前功能已经提供本地观测接口，但是否接入外部统计平台应单独确认隐私和数据保留策略。建议通过真实用户测试判断该体验是否提升了五阶段流程理解和模块进入率；如果不能证明实际价值，可以移除入口，原有首页工作流不会受到影响。
